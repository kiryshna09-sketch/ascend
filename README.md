# Ascend

Ascend is a free, installable web app for tracking daily tasks, streaks, and 30-day plant growth.

## Publish it for free

Upload the contents of this folder to a static HTTPS host. GitHub Pages can serve a public repository on GitHub Free. The app needs HTTPS for installation and offline support.

For GitHub Pages, create a public repository, upload these files, then enable Pages in the repository settings. The resulting `github.io` address can be shared with anyone.

## How each person's data works

Tasks, appearance settings, and history stay in that person's browser storage. The app has no account system or shared database, so data is not sent to a server and does not sync between devices. After the first online visit, the app shell is cached for offline use.

Visitors can install it from their browser's install or add-to-home-screen menu. Installation options vary by browser and device.
